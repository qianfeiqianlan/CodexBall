# CodexBall 桌面搭档迭代需求

> 更新：2026-10-24。状态：已完成 PNG 原型、Live2D 本机技术验证及交互收敛；正式原创角色、完整动作素材和分层换装仍待制作。本文件是当前需求基线，取代早期方案中冲突的交互说明。

## 多平台业务实现

相同业务需求现由 `CodexBall.Desktop` 在 Windows/macOS 共用实现；原 WPF/Store 版本保留。本文中的旧 Windows/WPF 技术说明适用于兼容版。新业务版的运行、平台服务、设置位置和验收边界见 [跨平台业务版](cross-platform-desktop.md)。共享渲染器位于 `CodexBall.Rendering`，继续固定 Native 5 R4.1。

## 产品方向

在 Codex 用量状态工具上增加软萌治愈的 Q 版桌面搭档，提供安静陪伴和轻互动。保留无需额外登录、快速查看额度的价值，不通过催促、责备或持续悲伤制造额度焦虑。

原创形象目标为两至三头身、圆润轮廓、奶油白与浅粉配色、宽松小外套。早期 AI PNG 三姿态用于概念和播放器验证；当前可选角色为官方免费示例模型，不代表原创形象已经完成。名字、发型和最终服装仍待确认。

## 当前已实现的展示与操作

| 项目 | 当前行为 |
| --- | --- |
| 外观入口 | 仅系统托盘右键菜单，统一为“外观”，不再单独提供桌宠模式开关 |
| 外观顺序 | CodexBall → 小春 Koharu → 春翔 Haruto → 虹色 Mao → 马克君 Mark；缺失或无效的本地包不列出 |
| 小球 | CodexBall，64 × 64 DIP，点击切换单环/双环；重新选择该外观恢复单环 |
| 桌宠 | 选择角色自动进入；小春/春翔画布 240 × 260 DIP，Mao/Mark 240 × 320 DIP，另加 20 DIP 页脚 |
| 用量 | 角色下方仅显示 4 DIP 高的细进度条，无文字和外层边框；点击查看短/长期额度、重置时间与更新状态 |
| 互动 | 呼吸、眨眼、窗口内视线跟随、头部点击动作、拖动摇摆和松手回弹；具体动作取决于模型资源 |
| 快捷键 | Alt+H 切换贴边隐藏，Alt+C 按菜单顺序循环外观并回到 CodexBall |
| 隐藏方向 | 左右间距除以工作区宽，上下间距除以工作区高，选择百分比最小的边 |
| 恢复 | 保留可悬停唤出的窄条，恢复先前可见位置；切换外观后限制在工作区内 |
| 可见性 | Codex 关闭时桌宠仍可显示；小球随 Codex 活动显示或隐藏；隐藏时暂停动画 |
| 语言 | 跟随系统（默认）、中文、English；立即切换并保存 |

窗口透明、无边框、不出现在任务栏、不主动抢焦点；置顶可通过托盘切换并保存。全局快捷键在小球启动时不可见的情况下也应注册。

系统语言以启动时 `CurrentUICulture` 为依据：`zh` 系列使用中文，其余使用英文。配置值为 `system`、`zh-CN`、`en-US`。旧设置缺少语言字段时默认跟随系统。

已移除 Haru、角色/小球右键菜单、专注模式、重新加载外观、打开外观文件夹和用户目录扫描。原 Haru、旧 PNG 或失效外观选择回退 CodexBall；旧 `FocusMode` 字段被忽略。选择新外观加载失败时保留当前外观；启动时外观失效或运行时渲染失败则回退小球。

## 动作协议和素材扩展

行为层通过 `ICompanionPlayer` 请求语义动作，支持播放、停止、暂停、恢复、帧更新和完成通知；具体 PNG 文件、Live2D 动作组由包配置映射。换完整角色或服装素材不应修改 Codex 用量逻辑。

| 标识 | 含义 |
| --- | --- |
| `Idle` | 待机 |
| `Pat` | 点击头部反应 |
| `Drag` / `Drop` | 拖动 / 松手 |
| `Sleep` | 应用内三分钟无互动 |
| `QuotaLow` | 低额度反馈 |
| `QuotaRecovered` | 额度重置恢复反馈 |

缺失动作回退待机；请求动作并不意味着模型已有对应专属动画。当前 Live2D 点击使用模型自带动作，拖动/松手使用程序化摇摆与弹簧回正。没有专属摸头、睡觉、被拎衣领或换装动画的完成承诺。

拖动优先于其他动作；额度事件不打断摸头和拖动，也不无限排队。低额度在剩余低于 20% 时触发，回到 25% 以上后重新允许提示。恢复要求同一时长窗口原重置时间已到、新重置时间向后推进且剩余额度增加；初次读取和断连后首次恢复不庆祝。未知额度不冒充零额度，不从额度推断任务是否执行或完成。

PNG v1 配置、裁切、序列帧和变体仍作为内部兼容能力保留；当前用户只能选择经过筛选的内置包。素材协议见 [外观包格式](companion-skin-format.md)，导入步骤见 [本地模型记录](imported-live2d-models.md)。开发脚本导入不等于开放用户导入功能。

## 技术与设置边界

- Windows x64 / .NET 9 / WPF；无数据库、后台服务或 WebView。
- 使用 `codex app-server --stdio` 复用本机登录，不索取 API Key，不读取浏览器 Cookie、私有令牌文件或私有 Web API。
- Core 负责 Codex 协议、解析、格式化及可独立测试的规则；WPF 消费 `StatusBallViewModel` 与 Core 模型。
- Live2D 为 Cubism Native 5 R4.1 Core + 社区 C# 适配层 + OpenTK 离屏渲染 + WPF 位图透明合成，要求 OpenGL 3.3。不能独立升级 Core；细节与局限见 [技术验证](live2d-technical-preview.md)。
- 切换外观释放旧播放器/纹理/GL 上下文；隐藏暂停更新，切回小球释放播放器。
- 设置保存在 `%LOCALAPPDATA%\CodexBall\settings.json`：位置、置顶、透明度、贴边隐藏、重置环、外观 ID、内部展示模式及语言。
- SDK、下载 ZIP 和导入模型不入 Git；重新克隆需执行准备/导入脚本。没有角色素材时仍可使用 CodexBall。
- 打包应用隐藏开机启动和自升级入口，并跳过 GitHub 更新检查。

## 已验证与待验证

已完成 Core 测试、WPF/PNG 播放器测试、四个真实模型的 OpenGL 帧验证、外观循环与设置持久化测试、中英文系统识别与即时切换测试。最近本机全量测试共 39 项通过；Release 构建无警告或错误。CI 排除 `Live2DGraphics`，不能用 CI 通过替代 GPU 验证。

后续验收仍需覆盖不同显卡与远程桌面、混合 DPI 多屏（100%/125%/150%/200%）、长时间运行和反复换装的资源稳定性、输入命中与桌面遮挡体验、MSIX 图形兼容性及正式分发授权。现有离屏测量不能代表最终桌面帧率或功耗。

# Live2D 技术验证（接入现有项目）

日期：2026-10-24。按用户选择，在现有项目中接入 Live2D，保留用量数据源、小球外观、透明窗口及本地设置，没有另建验证程序。最初使用 Haru 验证，随后已移除 Haru，当前只提供 CodexBall、小春、春翔、Mao 和 Mark。

## 运行

要求：Windows x64、.NET 9 SDK、支持 OpenGL 3.3 的显卡驱动。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Setup-Live2D.ps1
# 从 tmp/ 中的下载 ZIP 准备四个角色，需要 PowerShell 7
pwsh -File .\scripts\Import-Live2DModels.ps1
dotnet run --project .\CodexBall.App
```

若旧版正在运行，先通过托盘退出，避免单实例互斥让新版直接退出。从托盘“外观”选择角色自动进入桌宠，选择 CodexBall 回到小球。Alt+C 循环外观，Alt+H 切换贴边隐藏。角色自身没有右键菜单，不开放用户外观目录。旧 Haru、PNG 或不可用选择回退 CodexBall。

首次构建前执行准备脚本，或者用 `-SdkArchive <路径>` 提供官方 Native 5 R4.1 ZIP。脚本校验 SHA-256 后，复制 Windows x64 Core 与原始许可说明；角色由单独的导入脚本准备。下载文件与模型不提交 Git，运行时不需要联网。

## 验证范围

- 真正加载 `.moc3`、`.model3.json`、贴图、动作、表情和物理配置。
- 原生 Core 计算模型变形，OpenGL 渲染至 RGBA 离屏纹理，读回并转换为 WPF `Pbgra32` 位图。
- 透明背景保留，避免在 WPF 中嵌入原生子窗口造成的透明和叠层限制。
- 使用模型的呼吸、物理与待机动作，补充周期眨眼；指针在角色窗口内移动时平滑调整视线，离开后回正。不使用摄像头，不安装输入钩子。
- 点击头部根据素材包映射请求模型的动作组（例如 `Tap` 或空名称组），沿用模型自带淡入淡出。该动作用于验证交互触发，不代表已制作专属摸头动画。
- 拖动采用 WPF 鼠标捕获移动窗口，保持渲染循环运行；水平移动影响倾斜，松手通过阻尼弹簧回正。这里是程序化摇摆，不是专属“被拎衣领”动作。
- 隐藏、小球模式停止渲染订阅；切换外观释放模型、纹理和独立 GL 上下文。
- 不支持的动作使用待机；示例动作完成后恢复待机。播放失败时暂停并回到小球，提示具体问题。

## 技术选择与兼容性

本机虽有 MSVC 编译器，但缺少完整标准头文件与 Windows SDK，因此选用：

1. 官方 **Cubism SDK for Native 5 R4.1** 中的 Core DLL。
2. 第三方 `Live2DCSharpSDK.OpenGL/App/Framework 1.0.0` 处理模型、动作、物理和网格绘制。
3. `OpenTK 4.9.4` 创建隐藏的兼容模式上下文，目标 60 次/秒渲染回调。
4. `WriteableBitmap` 显示离屏结果，用量在角色下方以细进度条显示，点击打开详情。

这不是官方 WPF SDK。社区适配层需要单独维护与验证。测试发现 Native 5 R5 的 Core 已改变绘制顺序接口，当前社区适配层仍调用 `csmGetDrawableRenderOrders`，因此不能直接升级 Core。已固定匹配版本，并使用 `CopyToOutputDirectory=Always` 避免旧 ZIP 时间戳导致错误版本残留。

本版使用每帧 GPU 回读，便于验证透明合成，但会产生同步和带宽成本。后续可以研究共享 GPU 纹理，不能依据此验证直接断言最佳长期架构。MSIX、x86、ARM64 和远程桌面的图形兼容性尚未验证。

## 初步测量与测试

本机首次测量：NVIDIA GeForce RTX 2070，驱动 OpenGL 字符串 `4.6.0 NVIDIA 610.62`。早期 Haru 验证的 480 × 640 离屏分辨率（240 × 320 DIP，2 倍采样），120 次待机帧的渲染加回读平均约 **3.16 ms**，P95 约 **4.36 ms**。整组交互测试共渲染 271 帧。

该数字来自同进程的离屏渲染测试，不包含完整桌面合成、输入延迟和长期功耗，也不是实测桌面帧率。资源占用与混合 DPI 多屏拖动仍需真实使用确认。

```powershell
dotnet test
# 只有不带 GPU 的环境：
dotnet test --filter "Category!=Live2DGraphics"
```

GPU 测试验证透明像素、有内容的帧、随时间变化的画面、互动响应及实际主窗口渲染。PNG 播放兼容测试与协议/额度事件测试继续保留。CI 运行不依赖 GPU 的部分，真实图形测试在本机执行。

## 后续素材与换装

当前四个角色是官方免费示例模型，与正式原创 Q 版设定仍有差异。制作正式角色需要分层立绘、遮挡补画、网格绑定、表情、动作与物理调试。将新模型及动作导出成标准 Cubism 文件后，可通过素材包配置映射，替换现有示例角色，不需要重写用量逻辑。

模型更换已具备接口；同一模型内的服装分层开关、参数标准和跨服装动作兼容还没有在本次验证中实现。

CodexBall Privacy Policy

Last updated: September 16, 2026

CodexBall is a lightweight Windows desktop widget for displaying local Codex rate-limit status. This privacy policy explains what information CodexBall does and does not collect.

Information We Collect

CodexBall does not collect, transmit, sell, or share personal information.

Local Data

CodexBall stores lightweight local settings on your device, such as window position, opacity, always-on-top preference, edge-hide preference, and display mode. These settings are stored locally under your Windows user profile and are not uploaded.

Codex Account and Rate-Limit Information

CodexBall communicates with the local Codex app server on your device to display rate-limit status. CodexBall does not ask for API keys, does not read browser cookies, and does not directly access private token files.

Network Access

Non-Store versions of CodexBall may check GitHub Releases to determine whether an update is available. Microsoft Store versions use Microsoft Store update mechanisms and do not use CodexBall's built-in GitHub update check.

Third-Party Services

CodexBall does not include analytics, advertising, tracking SDKs, or telemetry services.

Data Sharing

CodexBall does not share user data with third parties.

Children's Privacy

CodexBall is not designed to collect information from children and does not knowingly collect personal information from children.

Changes to This Policy

This policy may be updated from time to time. Updates will be posted on this page.

Contact

If you have questions about this privacy policy, please contact the project maintainer through the CodexBall GitHub repository.
